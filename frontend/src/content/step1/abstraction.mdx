<Snippet id="numpy-init">

```python
import numpy as np

rng = np.random.default_rng(42)
W1 = rng.normal(0.0, 1.0 / np.sqrt(784), size=(784, 32))
b1 = np.zeros((1, 32))
W2 = rng.normal(0.0, 1.0 / np.sqrt(32), size=(32, 10))
b2 = np.zeros((1, 10))
```

</Snippet>

<Snippet id="numpy-forward">

```python
def relu(z):
    return np.maximum(z, 0.0)

a1 = relu(X @ W1 + b1)   # the hidden layer
logits = a1 @ W2 + b2    # the output layer, left linear
```

</Snippet>

<Snippet id="numpy-loss">

```python
z = logits - logits.max(axis=1, keepdims=True)   # stability
e = np.exp(z)
p = e / e.sum(axis=1, keepdims=True)

loss = -np.mean(np.log(p[np.arange(len(y)), y]))
```

</Snippet>
