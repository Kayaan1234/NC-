## The training loop and the data

The training loop is quite simple and incorporates all other sections we have previously covered. The major concept this code
block shows is epochs. An epoch is simply 1 forward and backward pass of the data, so the number of epochs is equivalent to the number of times we call update. 
Simple really!

```cpp
void train(Node& node, const Dataset& d, double lr, int epochs) {
    std::cout << std::fixed << std::setprecision(4);
    const int every = std::max(1, epochs / 10);
    for (int e = 0; e < epochs; ++e) {
        Node::Grad g = node.gradient(d.X, d.y);
        node.update(g, lr);
        if (e % every == 0 || e == epochs - 1) {
            std::cout << "epoch " << std::setw(4) << e
                      << "  loss " << node.binaryLoss(d.y, d.X)
                      << "  acc " << accuracy(node, d) * 100 << "%\n";
        }
    }
}
```

Accuracy is a simple metric to judge the strength of this simple model. Ideally, you want to split data into 2 distinct sets, one for training and one for testing,
but because this model is so simple, I thought it would be appropriate to only show its limitations without going too deep into proper machine learning technique.

```cpp
double accuracy(const Node& node, const Dataset& d) {
    std::size_t correct = 0;
    for (std::size_t i = 0; i < d.X.size(); ++i)
        if ((node.forward(d.X[i]) >= 0.5 ? 1.0 : 0.0) == d.y[i]) ++correct;
    return static_cast<double>(correct) / d.X.size();
}
```

This dataset, with only 4 points, will never ever get 100% training accuracy, because it is **not** linearly separable. Look at the graph, and
you will notice that it is impossible to draw a straight line that completely separates the two classes. You will always get one misclassified point, meaning 
the training accuracy is capped at 75%. On the other hand, look at the **tiny dataset**

This **is** an example of a tiny linearly separable dataset, we have a separating hyperplane that can perfectly separate the two classes, and therefore
given a suitable learning rate and number of epochs, we will get 100% training accuracy. The blobs dataset is an example of a multidimensional linearly separable dataset, in this case 4-dimensional. 
To separate the two classes, the resultant weights and bias create a 3D hyperplane.
